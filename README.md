# WonderKids • scripts

Допоміжні скрипти для проєкту ДивоСвіт / WonderKids.

- **`dev.sh`** — запускає dev-сервер застосунку (фронтенд + API з `app/api/*` в одному процесі Vite) на порту 4321 з доступом по локальній мережі (для телефона/планшета). Окремий бекенд не потрібен.
  ```bash
  ./dev.sh            # http://localhost:4321 (+ Network URL)
  ./dev.sh 4500       # інший порт
  ```

- **`autopush.sh`** — перевіряє репозиторії на зміни і, якщо є, автоматично комітить та пушить їх.
  ```bash
  ./autopush.sh                 # авто-повідомлення з датою/часом
  ./autopush.sh "fix: ..."      # власне повідомлення коміту
  ```
  Коміти створюються від імені приватного акаунта (через `git -c`, без зміни глобального конфіга).

- **`deploy-app.sh`** — комітить і пушить репозиторій `app/`, що запускає деплой на Vercel (фронтенд + serverless API в `app/api/*`). Перед пушем перевіряє production-білд.
  ```bash
  ./deploy-app.sh                      # авто-повідомлення коміту
  ./deploy-app.sh "feat: add login"    # власне повідомлення
  SKIP_BUILD=1 ./deploy-app.sh         # без перевірки білда
  ```
